# Документация проекта

Это учебный проект для практики Git.

## Основные команды Git

- git clone - скачать репозиторий
- git branch - создать ветку
- git commit - сохранить изменения
- git push - загрузить на GitHub

## Как использовать

1. Клонировать репо
2. Создать свою ветку
3. Добавить файлы
4. Загрузить на GitHub
